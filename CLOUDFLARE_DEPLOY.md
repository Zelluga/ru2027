# Деплой «2027» на Cloudflare — только через веб-панели (без командной строки)

## Схема

```
GitHub (репозиторий)          Cloudflare Pages            Cloudflare D1
  └─ public/  (интерфейс)  ──►  раздаёт HTTPS-стайт   ──┐
  └─ functions/ (бэкенд)   ──►  выполняет /api/*      ──┴─►  база tabs+expenses (SQLite)
```

- **GitHub** — только хранилище кода (не хостинг). GitHub Pages даёт HTTPS только для статики и **не умеет** запускать серверный код и базу — поэтому для нашего приложения он не подходит как хостинг.
- **Cloudflare Pages** даёт бесплатный HTTPS (`https://<имя>.pages.dev`) + выполняет бэкенд из `functions/`.
- **Cloudflare D1** — облачная SQLite-база для вкладок и записей.

---

## Шаг 1. Залить код на GitHub (веб)

⚠️ **В GitHub нельзя заливать `.env` (там токен бота)**, а также `data/` и `node_modules/`.

**Через веб (github.com):**
1. Откройте ваш новый репозиторий → кнопка **Add file** → **Upload files**.
2. Перетащите файлы проекта. Нужны минимум: папка **`public`**, папка **`functions`** и (по желанию) `README.md`, `.env.example`, `API_CONTRACT.md`.
3. Перед загрузкой убедитесь, что в выбранных файлах **нет `.env`** (если тащите всю папку — сначала удалите из неё `.env` и `data\`).
4. Внизу **Commit changes** → Commit.

> Надёжнее и проще — Git CLI: `git add .` сам не зальёт `.env`/`data`/`node_modules` из-за `.gitignore`. Но веб-вариант выше тоже работает, если вручную не заливать `.env`.

---

## Шаг 2. Создать базу D1 (Cloudflare)

1. Зайдите на [dash.cloudflare.com](https://dash.cloudflare.com).
2. Слева **Workers & Pages** → раздел **D1 SQL database** → **Create**.
3. Название базы: `2027-db` → **Create**.

Таблицы `tabs` и `expenses` создадутся автоматически при первом обращении (код сам делает `CREATE TABLE IF NOT EXISTS` и добавляет вкладки «Падл-пенис» и «Сука,Сочи»).

---

## Шаг 3. Создать Pages-проект из GitHub (Cloudflare)

1. В **Workers & Pages** → **Create** → вкладка **Pages** → **Connect to Git**.
2. Разрешите доступ к GitHub и выберите ваш репозиторий → **Begin setup**.
3. Настройки сборки:
   - **Project name** — например `app2027`.
   - **Production branch** — `main`.
   - **Build command** — оставьте **пустым**.
   - **Build output directory** — напишите `public`.
   - (Если файлы в репозитории лежат в подпапке — укажите её в **Root directory**.)
4. **Save and Deploy**. Через минуту получите адрес `https://app2027.pages.dev`.

---

## Шаг 4. Привязать D1 к Pages-проекту

1. Откройте проект Pages → **Settings** → **Functions** → блок **D1 database bindings**.
2. **Add binding**:
   - **Variable name**: `DB`  (обязательно именно так — код обращается к `env.DB`)
   - **D1 database**: `2027-db`
3. **Save**. Если Cloudflare предложит переразвернуть — согласитесь.

---

## Шаг 5. Добавить переменные и секрет токена

1. Проект Pages → **Settings** → **Environment variables** → **Add variable** (Production).
2. Добавьте:
   | Имя переменной | Значение | Секрет? |
   |---|---|---|
   | `BOT_TOKEN` | `ВАШ_ТОКЕН_БОТА` | **да** (переключатель «Encrypt») |
   | `OWNER_USERNAME` | `Depenz` | нет |
   | `OWNER_TG_ID` | (ваш числовой ID — опционально) | нет |
   | `DEV_MODE` | `0` | нет |
3. **Save**. После изменения переменных запустите деплой заново (Deployments → **Retry deployment**, либо сделайте новый push).

---

## Шаг 6. Привязать кнопку бота к адресу Mini App

Откройте в браузере (или в терминале) — подставьте свой `https://...pages.dev`:

```
https://api.telegram.org/bot<ВАШ_ТОКЕН_БОТА>/setChatMenuButton
```
…через тело `{"menu_button":{"type":"web_app","text":"Открыть 2027","web_app":{"url":"https://app2027.pages.dev/"}}}`.

Либо в BotFather: `/newapp` → укажите бота, название и URL `https://app2027.pages.dev/` — получите ссылку `t.me/<bot>/<app>`.

---

## Шаг 7. Проверка

1. Откройте бота `@ru2027bot` → кнопку «Открыть 2027» на телефоне.
2. При первом запуске появятся вкладки **«Падл-пенис»** и **«Сука,Сочи»**.
3. Добавьте запись на одном устройстве → на другом она появится в течение 5 секунд.

## Примечания

- **HTTPS** даёт Cloudflare автоматически (`*.pages.dev`, либо ваш домен через **Custom domains** в проекте).
- **Лимиты бесплатного тарифа:** Pages Functions 100 000 запросов/день, D1 5 млн строк чтения/день. Для 6 устройств при обычном использовании достаточно. Если приложение держать открытым круглосуточно на 6 устройствах — можно оптимизировать (объединить опрос в один эндпоинт), скажите — сделаю.
- Токен живёт только в переменных Cloudflare (секрет), в репозитории его нет.
